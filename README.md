# Signature Verification

## Overview

This repository contains tools for building and evaluating a signature verification pipeline.
It includes preprocessing utilities for cleaning handwritten signature scans, dataset auditing helpers, and a FastAPI-ready application scaffold.

## Repository structure

- `api/`
   - `main.py` — FastAPI application entrypoint scaffold
   - `routes/verify.py` — signature verification route scaffold
   - `inference.py` — inference utilities placeholder
- `data/` — raw signature dataset organized by subject
- `data_processed/` — output of the preprocessing pipeline
- `preprocessing/`
   - `preprocess.py` — image preprocessing pipeline
   - `audit.py` — dataset audit and quality checks
   - `fix_structure.py` — dataset folder and filename normalization
   - `fix_extensions.py` — image extension cleanup
- `models/`, `training/`, `notebooks/`, `frontend/` — additional project workspaces and experiments

## Dataset expectations

The pipeline expects the raw dataset in `data/` with the following layout:

```
data/
  SIG_0001/
    genuine/   ← 10 signature images
    forged/    ← 5 signature images
  SIG_0002/
    genuine/
    forged/
  ...
```

Each subject folder should be named `SIG_XXXX` and contain `genuine` and `forged` subfolders.

## Setup

Install dependencies using the provided requirements file:

```bash
python -m pip install -r requirements.txt
```

If you only need the preprocessing utilities, install at minimum:

```bash
python -m pip install numpy opencv-python-headless pillow pandas
```

## Preprocessing pipeline

The preprocessing pipeline is implemented in `preprocessing/preprocess.py`.
It performs the following steps on each image:

1. Convert to grayscale
2. Apply Otsu binarization
3. Ensure white background with black strokes
4. Crop to signature content with padding
5. Resize to a fixed `155×220` canvas with padding
6. Normalize pixel values to `[0.0, 1.0]`
7. Save the processed image as PNG

Run the full dataset preprocessing with:

```bash
python preprocessing/preprocess.py
```

Processed images are written to `data_processed/` with the same folder structure as `data/`.

## Dataset audit

Use `preprocessing/audit.py` to verify dataset structure and image consistency.
It checks:

- subject folder naming
- presence of `genuine` and `forged` folders
- expected image counts
- readable image files
- image dimensions and color modes

Run the audit with:

```bash
python preprocessing/audit.py
```

## Folder normalization

Use `preprocessing/fix_structure.py` to normalize raw dataset folders and file extensions.
This script:

- renames subject folders to `SIG_XXXX`
- renames label folders to `genuine` / `forged`
- normalizes image file extensions to `.jpg`, `.jpeg`, or `.png`

Run it with:

```bash
python preprocessing/fix_structure.py
```

## API scaffold

A FastAPI app scaffold exists under `api/`.
The service is expected to expose verification endpoints and inference logic, but the implementation is currently minimal.

## Notes

- `data/` is expected to contain raw scans and is not included in the repository.
- `data_processed/` is generated by the preprocessing pipeline.
- The repository is designed for signature verification research and model development.
